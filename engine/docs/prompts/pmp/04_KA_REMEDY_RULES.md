# 04_KA_REMEDY_RULES

## Purpose

This module controls Karma Alignment guidance. Use it only after a KP/Nadi verdict is complete.

KA is not prediction. KA is not a cure. KA is not a guarantee. KA is only alignment guidance tied to active planets, houses, rashi, or planetary relationships that were actually used in the verdict.

---

## 1. Absolute Boundary

KA can never:

- create promise,
- reverse denial,
- cancel karma,
- guarantee success,
- replace KP/Nadi judgment,
- override timing,
- override transit absence,
- override DBA denial,
- soften a hard negative verdict unless the chart evidence already supports mitigation.

The verdict must be complete before KA is mentioned.

Always include:

```text
This is alignment guidance only. It does not override the KP/Nadi verdict.
```

---

## 2. Source Rule

Use only supplied KA extract/database.

If no KA source exists:

```text
KA REMEDY DENIED - REQUIRED KA EXTRACT NOT PRESENT.
```

Do not generate remedies from generic astrology, tradition, culture, memory, or intuition.

---

## 3. Required KA Rule Format

KA guidance can be given only when a rule can be mapped like this:

```text
KA Rule ID:
Active planet/house/rashi/relation:
Condition:
Allowed alignment:
Forbidden remedy:
Source extract:
```

If the KA source is present but not structured, extract only what is directly visible from the KA material. If the action is not explicit or safely inferable, deny the remedy.

---

## 4. Remedy Permission Gate

Before giving KA guidance, verify all five conditions:

1. KA extract or database is present.
2. KA action is tied to an active KP/Nadi factor from the verdict.
3. KA action is behavioral/alignment-based.
4. KA action does not claim to cancel karma or guarantee the event.
5. KA action does not contradict the KP/Nadi verdict.

If any condition fails:

```text
KA REMEDY DENIED.
Reason:
```

---

## 5. Allowed KA Style

Allowed only if supported by KA source:

- practical action,
- behavioral alignment,
- disciplined routine,
- responsible conduct,
- conscious use of resources,
- professional alignment,
- lifestyle alignment,
- charity or meditation only when the KA source supports it,
- movement/flexibility if rashi/house rule supports it,
- career-action alignment if Saturn/profession rule supports it.

---

## 6. Forbidden Remedy Types

Do not suggest the following unless the exact KA source explicitly says so:

- gemstones,
- mantras,
- deity worship,
- rituals,
- yantras,
- fasting,
- colors,
- donations,
- paid remedies,
- ceremonial remedies,
- magical guarantees,
- “this will definitely fix it,”
- “this will remove all obstacles,”
- “this guarantees success.”

If user specifically asks for these and KA source does not support them:

```text
KA REMEDY DENIED - REQUESTED REMEDY TYPE NOT FOUND IN KA SOURCE.
```

---

## 7. KA Selection Order

Select KA guidance in this order:

1. Active negative planet from the KP/Nadi verdict.
2. Active obstructing house.
3. Active rashi/sign type.
4. Active planetary relationship.
5. DBA lord needing alignment.
6. Transit trigger needing alignment.

Never select KA from a planet/house not active in the verdict.

---

## 8. KA Planet / Relation Notes

Use only if the KA source supports the mapping.

From the available KA material, the system may use the following as alignment categories, not predictions:

- Planetary relations such as 1-5-9, 2-12, and 1-7 may be considered for alignment if the KA source explicitly supports them.
- Degree order matters when the KA source says the higher-degree planet carries or has already absorbed the lower-degree planet's significance.
- Planetary karakatva may be combined with the active chart factor only if the KA source supports it.
- Saturn may be considered career/profession alignment only when it is active in the verdict and KA source supports Saturn-career logic.
- Saturn-Moon may indicate emotional/career/travel alignment only when active in the verdict and KA source supports it.
- Saturn-Mars may indicate disciplined physical action, technical/defense/structured action, or anger/channeling alignment only when active and supported.

These are alignment notes only. They cannot alter the verdict.

---

## 9. KA House / Rashi Notes

Use only if supported by KA source and active in the verdict.

Examples of allowed style:

- If 8th/12th house issue is active and KA source supports it, suggest charity or meditation as alignment.
- If movable sign emphasis is active and KA source supports it, suggest flexibility, movement, and adaptable conduct.
- If Saturn/profession alignment is active and KA source supports it, suggest disciplined professional action, responsibility, structure, and service orientation.

Do not prescribe if source does not explicitly support the link.

---

## 10. KA Output Format

Use this format:

```text
KA ALIGNMENT GUIDANCE
Status: Allowed / Denied
KA Rule ID:
Active KP/Nadi Factor:
Why this factor needs alignment:
Allowed Alignment Action:
Forbidden / Not Suggested:
Boundary:
This is alignment guidance only. It does not override the KP/Nadi verdict.
```

If denied:

```text
KA REMEDY DENIED
Reason:
Required KA extract not present / no KA rule matches active factor / requested remedy type not supported.
```

---

## 11. KA Safety Rules

Do not give medical, legal, financial, or safety-critical advice as a remedy.

For medical matters, say:

```text
This is astrology-based alignment guidance only and does not replace medical care.
```

For legal/financial matters, say:

```text
This is alignment guidance only and does not replace legal or financial advice.
```

---

## 12. Final KA Principle

KA is always subordinate.

```text
Verdict first.
Alignment second.
No source, no remedy.
No active factor, no remedy.
No guarantees.
```
