## TRACK RULE

Only Essential tracks can deny the main event.

Modifier track:
changes type/location/condition but does not deny main event.

Outcome track:
judges benefit, loss, quality, stability, happiness, profit.

Process track:
judges step such as interview, exam, visa, loan, surgery, hearing.

Negative Risk track:
warns only if risk combination is clearly active.

For compound questions, do not collapse tracks.

Example:
“Will I get a job abroad?”
- Employment = Essential.
- Physical relocation = Essential only if user asks move/relocate/live abroad.
- Foreign company/client = Modifier.
- Income = Outcome.
